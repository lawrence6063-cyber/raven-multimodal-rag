1目标指标体系

2.1 检索侧（离线可算 · 无需 LLM · 进 CI）

以 chunk 级 graded relevance 为准，k ∈ {1, 3, 5, 10}（可配）。实现于 IRMetricsEvaluator（@register_evaluator("ir")）。

指标定义状态
hit_rate@ktop-k 内至少命中一个 grade>0 的 golden 计 1已有→@k化
recall@ktop-k 内命中相关数 / golden 相关总数增强
precision@ktop-k 内命中相关数 / min(k, n)新增
mrr@k首个相关结果 rank 的倒数（前 k 无命中记 0）已有→@k化
map@k平均精度 AP 的均值新增
ndcg@k归一化折损累积增益，支持 graded relevance核心补齐

nDCG 公式（BEIR / TREC 口径）

DCG@k = Σi=1k 2reli − 1log2(i + 1)   ·   nDCG@k = DCG@kIDCG@k
  • reli = 第 i 位结果相关度（未命中/不在 golden 记 0）。
  • IDCG@k：golden 相关度降序排列取前 k 的理想上界；IDCG@k == 0 时 ndcg@k = 0.0。
graded / 二值兼容规则（关键）
· EvalInput.relevance 非空 → 用分级值 0–3 算 DCG/IDCG（graded 模式）。
· relevance 为空 → 每个 golden 视为 grade=1（二值模式），nDCG 退化为二值 nDCG，旧 31 条数据零改动兼容。

4消融显著性（直击"31 条无统计意义"）

📈 Bootstrap 95% CI

对 per-query 指标重采样 bootstrap_samples（默认 1000）次，取 2.5% / 97.5% 分位为置信区间。

🎲 Paired Permutation

full vs 各消融，对配对差值做随机符号翻转置换检验（默认 10000 次）出 p-value。

no_dense        0.702 [0.66, 0.74]      0.590 [0.54, 0.64]     0.013 *
